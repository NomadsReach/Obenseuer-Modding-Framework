# What you can't do (yet)

- You can't move a landmark. Use `Remove` and then `Create`.
- You can't delete the marker object, only hide it. The game has no call to delete one.
- You can't make map pins that are not landmarks. The map only has landmarks and the player's own marker. For the player marker see the [Player](../player.md) page.
- You can't read landmark positions or points of interest.
- You can't read a landmark the game has not loaded.
- You can't remove a landmark the player already owns from the game. There is no call for it.
