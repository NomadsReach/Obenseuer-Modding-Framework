# Mods menu

These notes cover how your mod shows up in the game's Mods menu.

## Things to know

- Settings from `Config` show in the Mods menu under your mod's name. This is true for the classic menu and the web menu. ConfigurationManager (opened with F1) lists BepInEx plugins only, so it does not show framework mod settings.

## Limits

- An old framework does not load framework mods. Framework 0.10.0 and earlier skip them without a message, so a player on an old framework does not see your mod in the game.
