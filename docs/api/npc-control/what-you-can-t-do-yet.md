# What you can't do (yet)

- **You can't change an NPC's animation, sound, look or state.** Only the five parts above are changed.
- **A walk the game already started is not stopped by taking the NPC.** A walk that started before the take finishes or stops by the game's own rules. Only the hold stops new activity.
