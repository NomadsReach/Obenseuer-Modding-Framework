# Self-check

- **You can switch on two start-up checks in the framework's config.** Set `Debug.DialogueAuthoringSelfCheck` to log a check of the conversation rules, the line links and the speakers when the game starts. Set `Debug.DialogueResponsesSelfCheck` to log a check of how anchors are matched and how ids are given out for responses.
