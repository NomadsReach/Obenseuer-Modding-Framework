# Obenseuer Modding Framework

The Obenseuer Modding Framework is a base for mods of the game Obenseuer. It runs as a BepInEx 5 or BepInEx 6 plugin. It gives mods a shared settings menu, save data, game events, game helpers and safe patching. The framework ships as one zip with a BepInEx 6 build (`ObenseuerCore.dll`) and a BepInEx 5 build (`ObenseuerCore.BepInEx5.dll`).

## What is new in 0.10.0-beta

Version 0.10.0-beta adds calls for player shops, mod NPC routines, doors, furniture blueprints, housing, custom skills, dialogue and quests, the world, the HUD and multiplayer. It also ships a BepInEx 5 build next to the BepInEx 6 one, and WebUi is now an optional module. These are the main groups, not the whole list. The [status page](status.md#what-is-new-in-0100-beta) lists every addition and the changes a modder must know, and [features](features.md) shows where each part fits.
