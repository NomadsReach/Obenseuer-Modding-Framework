# Modder guides

Task-based guides for the Obenseuer Modding Framework 0.9.0. Each guide walks through one job. For reference pages, see `docs/API.md` and `docs/api/`.

- [getting-started.md](getting-started.md): install BepInEx and the framework, build a mod with csc, and use config, keybinds, events, save data, patching and logs.
- [content.md](content.md): add mod content such as items, recipes and furniture.
- [gameplay.md](gameplay.md): read and change game systems through the game API.
- [ui.md](ui.md): build Mods menu pages, UI windows and HTML views.
