Each page here covers one job. Start with [Your first mod](getting-started/first-mod.md). It gets a log line on screen in about five minutes. The other pages add one feature each, so read them in any order.

Install the framework first, using the [install page](../install.md).

- [Your first mod](getting-started/first-mod.md)
- [Logging](getting-started/logging.md)
- [Config](getting-started/config.md)
- [Keybinds](getting-started/keybinds.md)
- [Using events](getting-started/using-events.md)
- [Save data](getting-started/save-data.md)
- [Patching](getting-started/patching.md)
- [Packaging](getting-started/packaging.md)

When your mod works, read [Using the framework alongside other mods](multiple-mods.md) before you share it.
