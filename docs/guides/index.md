# Guides

These guides cover the parts of the game the framework touches. If you have not made a mod yet, start with [Getting started](getting-started.md).

- [Content](content.md): items, recipes and furniture.
- [Content models](content-models.md): 3D models for items and furniture.
- [Gameplay and economy](gameplay.md): the player, survival, the world, money and jobs.
- [UI and HTML views](ui.md): Mods menu pages, windows and WebUi views.
- [Using the framework alongside other mods](multiple-mods.md): what happens when two mods use the same call.

## API pages for newer areas

Each of these areas has an API page with the details:

- [Player shops](../api/economy.md#player-shops): furniture managers the player runs as shops.
- [Doors and level changers](../api/doors.md): door and level changer positions.
- [Mod NPC routines](../api/modnpc-routines.md): weekly routines and orders for mod NPCs.
- [Furniture blueprints and flatpacks](../api/furniture.md#blueprints-and-flatpacks): crafting blueprints and the packed form of mod furniture.
- [Custom skills](../api/customskills.md): skills of your own in the character panel.
- [Dialogue](../api/dialogue-authoring.md) and [quest authoring](../api/quest-authoring.md): conversations and quests from code.
- [Debug](../api/debug.md): the master trace switch and the self-checks.
