# Guides

The guides are step-by-step walkthroughs. Each one takes a job, such as adding an item or building a window, and walks you through it from an empty project to a working mod. They are for when you have made your first mod and want to do something bigger.

If you have not made a mod yet, start with [Getting started](getting-started.md). It gets a log line on screen in about five minutes, and every guide here builds on the project it makes.

## The guides

Read them in any order. Each page tells you what to set up first.

- [Content](content.md): add items, recipes, icons, furniture, loot, shop stock and mail.
- [Content models](content-models.md): give an item or a piece of furniture a 3D model.
- [Gameplay and economy](gameplay.md): read and change the player, survival, the world, money and jobs.
- [UI and HTML views](ui.md): make Mods menu pages, windows and HTML panels.
- [Using the framework alongside other mods](multiple-mods.md): what happens when two mods use the same call, and how to avoid clashes.

## Short recipes

The [cookbook](cookbook/index.md) has small, one-job recipes you can copy, such as giving the player an item or paying them money.

## Newer features

These areas do not have a walkthrough yet. Each one has an API page that explains it:

- [Player shops](../api/economy/player-shops.md#player-shops): furniture managers the player runs as shops.
- [Doors and level changers](../api/doors.md): the positions of doors and level changers.
- [Mod NPC routines](../api/modnpc-routines.md): weekly routines and orders for NPCs that your mod adds.
- [Furniture blueprints and flatpacks](../api/furniture/blueprints-and-flatpacks.md#blueprints-and-flatpacks): crafting blueprints, and the packed form of furniture from mods.
- [Custom skills](../api/customskills.md): skills of your own in the character panel.
- [Dialogue](../api/dialogue-authoring.md) and [quest authoring](../api/quest-authoring.md): write conversations and quests in code.
- [Debug](../api/debug.md): the master trace switch and the self-checks.

## Where to go next

Start with [Content](content.md) if you want to add things to the game, or [Gameplay and economy](gameplay.md) if you want to change how it plays.
